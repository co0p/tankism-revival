# Learning log

This is the durable record of what building Tankism teaches us. Add an entry only after implementation or an experiment provides evidence; do not fill it with generic summaries copied from external sources.

## How to write an entry

For each completed learning slice, record:

- **Question:** the concrete ECS or game-programming question explored;
- **Implementation:** the smallest Tankism feature used to explore it;
- **Evidence:** relevant tests, measurements, screenshots, recordings, or playtest observations;
- **Lesson:** what the implementation demonstrated;
- **Tradeoff:** what the chosen approach makes easier or harder;
- **Next trigger:** the observed condition that would justify revisiting the design.

Prefer links to code, tests, and decision records over duplicating their contents here.
